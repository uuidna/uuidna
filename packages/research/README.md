## What this package is

A domain-scoped view over the root `@uuidna/uuidna` package. The implementation lives in the root `src/` (sealed by the determinism gates); this package re-exports exactly the research surface. The captain-claims generators (`gen:claims`, `seal:audit`) run the root's scripts via workspace scripts — the audit pipeline stays one pipeline.

## Honest scope

Research here extracts PROVENANCE and STRUCTURE, never meaning; novelty is content-address uniqueness. A publication publishes only when the honesty gate clears and corroboration holds (≥2 sources) — the gate verifies citations of sealed theorems, not world events. Integrity, not truth.

# Reading dimensions <Badge type="tip" text="◈ on every page" />

**The reading experience is an involution.** The ◈ control in the corner of every page folds the site between
its **full** pole and its **simple** pole — and folding twice returns exactly where you started, the same way
the diamond reflection pairs every digit with its mirror ([diamond_involution](/theorem/diamond_involution)) and
holds one fixed centre ([involute_centre](/theorem/involute_centre)). Complexity is never destroyed, only
folded — one click back.

## The five dimensions

Each dimension is its own toggle, named by its two poles. Set any mix; the master **fold all** takes them all to
one pole at once.

| dimension | full pole | simple pole | what folds |
|---|---|---|---|
| **aura** | glow | plain | the A432 colour rays and rails on theorem lists |
| **formulas** | stated | named | inline Lean statements in lists — the proof stays on its page |
| **meta** | woven | bare | the principle · skill lines under each entry |
| **density** | air | compact | spacing — the same content, less air |
| **motion** | alive | still | animations and transitions |

## How it holds

Your choice is written to this browser's storage only — **nothing is sent**. It applies as `data-dim-*`
attributes on the page root, and CSS does the folding, so every page — including all generated theorem
pages — obeys without regeneration. The defaults are the full pole: the fold adds a power, it breaks nothing.

The centre of the fold is the digit 5 — the strip's one fixed heart, the only digit carrying all three singular
roles ([only_five_carries_the_three_singularities](/theorem/only_five_carries_the_three_singularities)) — which
is why the ◈ glows the sequence green exactly when the site is fully folded to simple.

## Why an involution

A settings panel usually accumulates: more switches, more states, more ways to be lost. An involution cannot
be lost in — from any mixture, **fold all** reaches the simple pole, **unfold all** reaches the full pole, and
each single toggle is its own way back. The structure is the same one the ledger proves: self-inverse, closed,
no islands, one centre.

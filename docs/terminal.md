# The terminal <Badge type="tip" text="the toolbox, live" />

> This path's **sealed meaning** is busybox — *"Size optimized toolbox of many common UNIX utilities"*
> ([`the_terminal_is_the_toolbox`](/theorem/the_terminal_is_the_toolbox)) — and on this computer the toolbox
> **is** the MCP: the terminal below speaks the wire's own JSON-RPC to [`/mcp`](/mcp), so every command passes
> the same sealed gate, deposits the same two coins, and returns the same receipt as any MCP client
> ([`captain_commission_two_coins`](/theorem/captain_commission_two_coins),
> [`two_coins`](/theorem/two_coins)). A singularity, not a mirror: this page carries **no tool list of its
> own** — the toolbox is learned live from `tools/list`, so there is nothing here to drift.

<UuidnaTerminal />

Nothing typed here is ever executed as a shell command — a line is **data**: parsed by the pure app
([`src/quantum/apps/terminal.ts`](https://github.com/uuidna/uuidna/blob/main/src/quantum/apps/terminal.ts)),
enveloped as JSON-RPC, answered by the wire, and the whole transcript compiles to 32 hexbit states like any
spec ([`a_spec_compiles_to_hexbits`](/theorem/a_spec_compiles_to_hexbits)). This page took its route from the
[default install](/os) — the path was sealed first, and now serves what it means: a **served page has
priority**, and everything unserved falls to the [audit that catches all](/theorem/home_reaches_every_install).

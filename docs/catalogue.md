# The catalogue <Badge type="tip" text="full census · searchable" />

> The [default install](/os) closes at **25 paths** — what boots. Alpine publishes **28,630** packages on the
> pinned branch; this page is the editorial route for **all of them**. Each row is upstream's published tuple
> (name, version, checksum, description) compiled to 32 hexbit states — the same mint as `apk info` and
> `uuidna_exec man`, never binary execution ([`the_os_is_bootable_quantum`](/theorem/the_os_is_bootable_quantum)).

Every package also has a path: `/catalogue/<name>` — audited like the install routes, resolved by the
[404-as-audit](/theorem/home_reaches_every_install) when the book does not yet carry a dedicated page.

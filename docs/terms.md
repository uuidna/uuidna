# Terms

> An agent registers at qpu.uuidna.com by accepting these terms and the licence; it then reads the Payload MCP find-only, writes nothing beside the four sealed collections, and claims no quantum hardware. Canonical at uuidna.com/terms.

This page is the **canonical terms** (recorded as receipt `14f81232-6413-8419-9cd5-0a1a72469887`, the content-address
of the quoted line above — recompute it with `uuidna_address`). A registration accepts two receipts: this one and the
[licence](/license)'s `9ffcda04-5adc-872e-9358-6b831bbd0c0d`. Editing either line is a new receipt, so every earlier
acceptance still names the exact words it accepted.

## What an agent accepts

- **The licence.** CC BY-NC-ND 4.0, as the [licence page](/license) states it.
- **Reads, not writes.** After registering, the agent reads the Payload MCP find-only across pages, users, media and
  tenants. Writes happen in the Payload admin backend, authenticated, and never beside those four collections.
- **Honest scope.** The agent claims no quantum hardware. What qpu.uuidna.com serves is classical computation over
  content-addressed receipts.

## What a registration records

One user in `users` carrying both receipts, with occupancy `personal`. Its acceptance is logged as one address: the
content-address of the agent's handle and the two receipts. Nothing else is kept. See [privacy](/privacy).

## What this page is not

Not a signed agreement, legal advice, or a compliance opinion. It is a fingerprint of which words were accepted:
integrity, not truth ([`provenance_integrity_not_content_truth`](/theorem/provenance_integrity_not_content_truth)), so
the ruling on any dispute is a human's and a court's, never a fold's.
